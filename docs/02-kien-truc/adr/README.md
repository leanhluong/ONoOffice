# ADR — Nhật ký quyết định kiến trúc

> **Chưa có ADR nào.**

Mỗi quyết định lớn = 1 file `ADR-NNNN-ten-ngan.md`, dài khoảng 15 dòng, theo đúng 5 mục:

```
## Bối cảnh      · đang vướng chuyện gì
## Các lựa chọn  · đã cân nhắc những cách nào
## Chốt          · chọn cách nào
## Đánh đổi      · mất gì khi chọn cách đó
## Học được gì   · nối về Q&A/Ontap nếu có
```

Mục **Đánh đổi** là mục bắt buộc. Một quyết định không mất gì cả thì đó không phải quyết định.
